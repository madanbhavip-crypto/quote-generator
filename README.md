# 💭 Random Quote Generator

A lightweight, single-page web app that displays a random inspirational quote 
at the click of a button. Built using vanilla HTML, CSS, and JavaScript — no 
frameworks or libraries required.

## ✨ Features
- Randomly selects a quote from a curated list
- Clean, responsive UI with smooth hover effects
- Displays quote author along with the quote
- Beginner-friendly project demonstrating DOM manipulation

## 🛠️ Built With
- HTML5
- CSS3
- JavaScript (Vanilla)
